## What this changes

Phase-5 packaging of the gateway decision (operator log `mcp_gateway`): container
image, CI smoke, GHCR publication, and the Arcane stack template — mirroring the
operator's paperbroker-screener deployment conventions 1:1.

### Files

- **`Dockerfile`** — `python:3.13-slim`, non-root uid 10001 (CWE-250 convention),
  fixed container port 9160, `GATEWAY_HOST=0.0.0.0` inside the container (the
  module default stays `127.0.0.1` for host-local runs; exposure is controlled
  only by the LAN-only host publish), non-root `USER gateway` before `CMD`.
  HEALTHCHECK polls `/healthz`, which deliberately makes NO backend/database call
  — a restarted xang backend can never flip the container unhealthy (phase-5
  judge convention).
- **`.github/workflows/docker-publish.yml`** — GHCR publish on `main` pushes:
  `ghcr.io/markusdauner1974-droid/xang-mcp-gateway:latest` + `:sha-<commit>`,
  arm64+amd64, identical SHA-pinned action set as the operator's paperbroker
  pipeline (checkout v7.0.1, qemu v4.4.0, buildx v4.4.1, login v4.6.0,
  build-push v7.4.0). `GITHUB_TOKEN` `write:packages` suffices (no secrets).
- **`tests.yml`** — new `docker-smoke` job: builds the image and runs a container
  with stub envs (backend pointed at a dead port ON PURPOSE) — the smoke proves
  the container boots and answers `/healthz` 200 with zero external calls, then
  reports Docker health `healthy` and cleans up.
- **`docker-compose.yml`** — Arcane import template: GHCR image default,
  external `md-netzwerk` attachment (backend + postgres reachable by container
  name), LAN-only bind `${LAN_IP:-192.168.178.10}:${HOST_PORT:-9160}:9160`
  (no router forward — operator rule), and mandatory secrets via
  `${VAR:?...}` so an import never deploys with missing credentials
  (paperbroker PR #7 lesson).
- **README** — deployment section incl. the suggested Arcane env block and the
  operator SQL for the read-only user (`xang_ro`: `USAGE` + `SELECT` on
  `stock_feature_daily`/`feature_runs` only) — the production DSN decision stays
  with the operator.
