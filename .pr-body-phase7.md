## Phase 7: local `market_calendar_status` tool (canonical calendar facts)

### Problem

Hermes needs the exact `expected_trading_date` fact to evaluate a published
xang run's freshness deterministically (EVA freshness rule):

```
expected_trading_date = market_date if is_trading_day else last_completed_trading_day
```

A mid-session trading day therefore expects TODAY, never yesterday. The backend
MCP exposes no calendar facts; the canonical `MarketCalendarService` lives only
inside the backend image. **The gateway must never grow its own calendar logic.**

### Change (minimal, additive)

- NEW `src/xang_mcp_gateway/calendar.py` — canonical-service bridge:
  - lazy load of the verbatim-copied backend tree,
  - import shim for the canonical tree's `Settings()` loader (harmless
    `DATABASE_URL` placeholder; no DB connection is made, redis stays optional
    via the backend's own import guard),
  - fail-closed error envelope on ANY failure (`calendar_status: "error"`,
    `expected_trading_date: null`, no guessed dates),
  - `calendar_source: xang_market_calendar_service`.
- `config.py` — `LOCAL_TOOLS` surface (+ `backend_visible_tools` split) and the
  `calendar_app_root` setting (`XANG_CALENDAR_BACKEND_APP_ROOT`).
- `app.py` — local `tools/call` handler answered BEFORE the backend round trip
  (request-id preserved; text mirror + structuredContent like backend answers)
  and `tools/list` advertisement of the local tool (13 visible tools now).
- `Dockerfile` — backend stage pinned **by digest** (the image the production
  stack runs, verified 2026-10-15): canonical app tree + the calendar manifests
  copied 1:1 (`/opt/stockscanner/market-calendars` ->
  `/opt/xang_backend/market-calendars`), `MARKET_CALENDAR_DATA_ROOT` mirrored.
  Pin-refresh procedure documented in README.
- `pyproject.toml` — canonical-tree deps pinned to backend versions:
  `exchange-calendars==4.11.1` (4.13.x changes post-close semantics of
  `last_completed_trading_day` — measured live), `pandas>=2.2.0,<2.3` (2.2.0
  itself has no CPython 3.13 wheels), `pydantic-settings>=2.0`, `tzdata>=2024.1`.
- `README.md` — tools section (passthrough 12 + local 1), pin-refresh
  procedure, status update. Existing code/tests unchanged otherwise
  (allowlist/healthz assertions updated to 13 visible tools).
